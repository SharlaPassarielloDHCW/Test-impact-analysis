Two Tetris generations

Both games came from the same seed. Generation 001 used the unvalidated loop. Generation 002 used a planner, doer, and validator, with testability as the validator lens.

Result

Validation made a visible architectural difference: generation 002 separates pure game rules from terminal I/O and exports the rules for direct tests. Both versions remained playable. Generation 002 fills the 24-row allowance exactly; generation 001 uses 23 rows.

Differences supported by recorded validator findings

Recorded finding

Imports have no terminal side effects

The plan records two iterations on startup rendering. Generation 002 now exports renderStartup(), returns rendered text, and writes it only when run as the entry point.

Recorded finding

Randomness is injectable

The plan records that spawnPiece and tick depended on Math.random(). They now accept a random source, allowing deterministic tests.

Recorded finding

Styling can be deterministic

The plan records reliance on the global Chalk instance. renderGameState now accepts a Chalk instance, so tests do not depend on terminal color detection.

Recorded finding

Game rules are isolated

Generation 002 has a separate game.js. Collision, movement, rotation, drops, line clearing, scoring, speed, settling, input decisions, and ticking are exported independently of terminal I/O.

Other differences between generations

  • Not tied to a finding Generation 002 adds a next-piece preview, wall kicks, double-width cells, ESM modules, Chalk, and ansi-escapes.
  • Not tied to a finding The task breakdown differs: generation 001 used eight smaller tasks; generation 002 used four broader tasks.
  • Local edit The current generation 001 working copy contains uncommitted demo/autoplay behavior. The validator did not cause that difference, and it was preserved during this work.
  • Inference Two independent agent builds can vary even with the same seed, so display and dependency differences cannot be attributed to validation unless the plan records a related finding.

Recorded evidence

Generation 002’s plan contains four explicit testability findings under its first task. All are marked resolved. The final plan is complete, the target is clean, and its work and plan are committed. The factory acceptance suite passed 39 of 39 non-real-agent examples.
