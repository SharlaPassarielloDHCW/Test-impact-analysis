#test impact analysis

For a team of test engineers
who have a long execution time of their fully automated regression test pack
test impact analysis
helps them target and execute only the specific regression tests that have been impacted by the code changes
through detailed analysis of code changes, regression tests, and business-workflow impact

The capstone implementation lives in `test-impact-analysis/`. Its current
analysis target is the Task Desk website and functional tests in `impact-demo/`.
Each iteration goal in `iterations/` is a seed for work on the analyzer.
